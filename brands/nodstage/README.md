# Nodstage reels

Second brand on the same engine. Build a reel the same way as 10-key ones, from the repo root:
`python3 engine/build.py brands/nodstage/reels/<name>` (scene.html paths assume this depth: ../../../../ for engine and node_modules).

Brand: page #ECEEF1, ink #16181D, magenta #D1176F, yellow highlight #F4D23C, headlines Archivo 800, body Inter.
Presenters: Nico (look "nico") and Remi the artist (look "artist", points with a paintbrush). Not Tara: she is 10-key's.
Voice: Kokoro am_michael, speed 1.0. Kokoro says "Nodstage" as "nod stage"; Whisper hears two words, so the phrase
containing it needs an explicit word count, e.g. [7, "In [Nodstage,] every round is counted"].
Footage: real app screenshots from nodstage.com/landing/*.webp and the landing page's "you're the client" demo.
Never use the landing page's sample testimonials in a reel.
Audience: design and branding studios, web agencies, video studios, marketing teams, social agencies, freelancers.
