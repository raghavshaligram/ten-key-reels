# Nodstage — "One client, start to finish" (mid-century cartoon)

Use case: an onboarding / service card. Six numbered steps, one hand action per step, 28.6 s, 1080x1920, 30 fps.

Structures considered: (a) a set-up guide, six numbered steps with a medallion iris between each (chosen: the steps ARE the product);
(b) a do/don't split, chaos on the left, Nodstage on the right; (c) the result first (a paid invoice), then how it got there.

Logline: one client goes from booking to testimonial without leaving one workspace.
Opening: the six numbered medallions stamp on under "One client, start to finish" (hook in under 2 s); we iris through medallion 1.
Native move / peak: step 4. The client's comment bubble unfolds into a change-order card under a sunburst; music drops out for the beat before the glove presses Approve.
Payoff: the six medallions return and close into one ring (function into ornament) around the Nodstage logo. Ending: held still for 3 s.
Camera: slow push (hook, proof), iris through each medallion (x6), round call-out with leader line (comment), colour-block wipe up (close), pull-back reveal of the ring.
Presenter: a held body; only the arm changes pose (rest, point, present). The big glove does every press.
Sound: cool-jazz sketch (vibraphone chord per step, walking pizz bass, brushes), ducked under the existing Kokoro voice; foley on every action; silence before Approve.
Data: demo data only (Northbeam Studio, Hannah Brooks, Fernhill Coffee Co.). No testimonial quote is shown, only the request.
