# Topic bank

One reel per day. Pick the topic used least recently (check `log.md`), unless the user has asked for one.
Every fact in a script has to be true on the live site or in one of its guides. When unsure, open the guide and check.
Numbers shown on screen come from the real run that `build.py` records; the script never promises a number the run might miss.
