The 10-key test on our site has a ZIP code mode. Some codes are 5 digits. Others are 9, with a dash in the middle, and you type the dash on the minus key of the number pad.

Accuracy is counted per entry. One wrong digit in a 9-digit code and the whole entry counts as wrong.

In the reel, every code in a real minute was checked before Enter. The result came back 21 of 21 correct, 100% accuracy.

So take your time on the long codes. You can practice the ZIP code mode for free on our site.
